# CSV (comma seperated values)

* most common import and export values for spreadsheets and databases.

## Common Usage in Python

* csv.reader - returns a reader object that will process the given csv file
* csv.writer - returns a writer object that converts the users data into delimited strings on a given file like object
* csv.DictReader - like reader but maps the information in each row to a dict
* csv.DictWriter - like writer but maps dictionaries to output rows
