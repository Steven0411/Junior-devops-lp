# JFrog Artifactory

## Key features

* Universal Repository manager:
  * supports a wide range of artifact types e.g. maven, Gragle, npm and docker
* Securing the entire SDLC (software development lifecycle):
  * robust security features e.g. role-based access control, permissions and compliance tools to make sure artifacts meet regulatory requirements
* Delivering applications at scale:
  * designed to handle large-scale deployments, support high-traffic environments and distributed teams
  * efficient caching mechanisms ensure that artifacts are delivered quickly and reliably
* Hybrid and multi-cloud environments:
  * can be used on your own infrastructure, in the cloud or use SaaS for flexibility
* Universal binary repo manager:
  * supports all major package formats
* Extensive metadata:
  * provides full metadata for all package formate for both artifacts and folders
* Kubernetes:
  * allows you to deploy containerized microservices to the kubernetes cluster
* High availability:
  * live failover and non-disruptive production upgrades
* CI server integration:
  * suports buld integration on common CI servers, cloud based servers or standalone without a CI server.
* Custom API-driver automation:
  * through the api you access its features anywhere in the dev cycle autonomously
* Advanced search:
  * artifactory query languange (AQL) allows for a lot of flexibility when searching for artifacts
* SaaS:
  * allows users to manage, control and distribute high volumes of software across multiple locations
